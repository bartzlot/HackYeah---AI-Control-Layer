How it works

One decision per request. Strictest verdict wins.

01
Intercept

DNS + TLS on the network path, or a base URL. Nothing to set in the tool.

02
Identify

Who sent it, from which tool, to which model. Budget reserved.

03
Inspect

Secrets, personal data, injection signatures EN + PL. A local AI cascade for the gray zone.

04
Decide

The strictest action of all controls wins. Engine errors fail closed.

05
Answer

In the client's own API format, so the agent keeps working. Audited.

Action lattice allow< log< warn< redact< block

Anthropic Messages, OpenAI Responses and Chat Completions, streaming included. Raw prompt text is never stored.
